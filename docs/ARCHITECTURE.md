## 数据流

### 1. 用户发送消息

```
用户 → 钉钉客户端 → 钉钉服务器 → Stream SDK → 连接器
```

### 2. 消息处理

```
连接器 → 消息去重 → Session管理 → 命令解析 → OpenClaw Core
```

### 3. AI 处理

```
OpenClaw Core → Agent调度 → AI API → 流式响应
```

### 4. 响应返回

```
流式响应 → AI Card → 钉钉服务器 → 用户客户端
```

## 核心模块

### 1. 消息去重模块

```typescript
// 防止同一消息被重复处理
const processedMessages = new Map<string, number>();

function isMessageProcessed(messageId: string): boolean {
  return processedMessages.has(messageId);
}
```

### 2. Session 管理模块

```typescript
// 管理用户会话状态
interface UserSession {
  lastActivity: number;
  sessionId: string;
}

const userSessions = new Map<string, UserSession>();
```

### 3. 流式响应模块

```typescript
// 支持 AI Card 流式输出
async function streamResponse(
  content: string,
  sessionId: string
): Promise<void> {
  // 分块发送
  for (const chunk of splitContent(content)) {
    await sendAICard(chunk, sessionId);
  }
}
```

## 扩展点

### 1. 自定义命令处理器

```typescript
connector.registerCommand('/custom', async (msg) => {
  return '自定义响应';
});
```

### 2. 中间件

```typescript
connector.use(async (msg, next) => {
  // 前置处理
  await next();
  // 后置处理
});
```

### 3. 事件监听

```typescript
connector.on('message', (msg) => {
  console.log('收到消息:', msg);
});
```
